# example-shop

Working ecommerce reference application demonstrating TrailGate integration: Server SDK usage, consent UX, and a simulated wallet with real authorization and accounting semantics (integer minor units, reservations, refunds, reconciliation).

Owner: D3 (see `internal/TEAM.md`).

Status: directory reserved. The framework and dependency choices are D3's decision in Phase 3, so no scaffold is committed yet. The app must remain a consumer of the protocol: TrailGate interoperability must not depend on ExampleShop.
