# Blogarithm implementation status

## Complete

- Public blog: homepage, featured/recent cards, tags, search, article
  pages, comments, reading layout.
- Auth: register, sign in/out, scrypt passwords, DB sessions, CSRF on all
  mutating forms.
- Workspace: overview stats, post list with filters/actions, editor
  (markdown + preview), comments management, notifications, settings,
  agent access (grant list + revoke).
- Post lifecycle: draft -> published -> draft, soft delete + restore, all
  transitions server-validated.
- Comments: per-post `comments_enabled` enforced server-side; existing
  comments preserved when closed.
- Notifications: generated by real events, unread counts, mark read/all.
- TrailGate: discovery, grant request, consent UI (verbatim effective
  scope, checkbox narrowing), redemption, status, revocation, all via
  `@trailgate/server`. 15 agent API routes through `tg.protect`.
- Durable sqlite port stores (grants, requests, keys, nonces,
  idempotency, rate limiter, audit, approvals).
- Demo agent: 11-step scripted scenario, `--manual` browser-consent mode.

## Test results (actual)

- `corepack pnpm test`: 7/7 pass — publishing workflow, comment settings,
  cross-user isolation, full TrailGate lifecycle (draft allowed / publish
  denied / second grant publishes / delete denied / revoke denies),
  persistence across restart, demo account.
- `corepack pnpm typecheck`: clean.
- `corepack pnpm demo`: all 11 steps verified live, receipts verified.

## Partial / limitations

- Editor is a markdown textarea with preview, not a rich-text library.
- `post:{user}` scope binds posts existing at consent time; later posts
  need re-consent (spec semantics, shown as the second consent step).
- `approval_threshold` constraint wired but unused by routes.
- TLS needs dev certs; demo uses loopback transport (same signed URLs).
- No email verification, password reset, or account deletion (demo scope).

## Commands

```bash
corepack pnpm start     # app at http://127.0.0.1:3401
corepack pnpm demo      # scripted agent scenario
corepack pnpm test      # acceptance suite
```
