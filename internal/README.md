# Internal

Team collaboration documents. These files are internal project material: they exist for the people building TrailGate, not for protocol implementers or external readers.

They are tracked in git because the team collaborates through the repository. Keep that in mind when editing: no secrets, no credentials, no personal information beyond what the team has agreed to record.

| File | Purpose |
| --- | --- |
| `TEAM.md` | Who owns which workstream and how the team coordinates. |
| `PHASES.md` | Staged build plan, dependencies, gates, milestones. |

Nothing in this directory is part of the protocol specification. Normative protocol material lives in `spec/`; public project documentation lives in `docs/` and the repository root.
